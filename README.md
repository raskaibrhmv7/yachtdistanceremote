# Яхт-менеджер

Мобильное приложение на React Native и Expo.

## Запуск

1. Установите Node.js LTS.
2. В папке проекта выполните `npm.cmd install`.
3. Запустите `npm.cmd start`.
4. Для телефона установите Expo Go и отсканируйте QR-код из терминала. Телефон и компьютер должны быть в одной сети.

Команды `npm.cmd run android`, `npm.cmd run ios` и `npm.cmd run web` запускают соответствующие платформы. Для Android-эмулятора нужен Android Studio; для iOS-симулятора — macOS с Xcode. Веб-версию можно открыть в браузере.

Проверка TypeScript: `npm.cmd run typecheck`.
